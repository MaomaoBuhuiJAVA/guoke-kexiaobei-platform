# 排行榜、卡片与实验弹窗布局修正

- 首页与资源库共用品牌和奖杯组件，手机端Logo、文字和奖杯的位置一致；奖杯按用户提供的金色造型以本地SVG实现，替换原线框图标。
- 卡片不再另起互动条：点赞数量与眼睛浏览数放在白色内容区右下角，点赞按钮位于卡片打开按钮之外，避免嵌套按钮和误开详情。卡片不显示评论数量；评论区保留在资料详情中。
- 实验上传弹窗通过Portal挂载在body，显式固定居中，按可用视口限制宽高，标题和提交操作可见，表单内部滚动；背景滚动在弹窗打开时锁定，关闭后恢复。
- 每分类排行榜前十显示资源已公开的作者/提供者信息；实验没有author字段时读取公开简介中已有的“实验大玩家”署名。沿用现有公开字段的姓名处理，不读取或公开注册账号信息。没有署名显示“未署名”。前三行使用金、银、铜色背景、左边框与更大的标题突出。
