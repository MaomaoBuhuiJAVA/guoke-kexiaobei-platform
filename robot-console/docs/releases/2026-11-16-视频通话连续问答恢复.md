# 视频通话连续问答恢复

日期：2026-11-16

## 问题与修复

用户在 iOS 上正常继续说话时，已完成识别的通话突然出现“通话服务遇到问题”。通过实际通话控制器、生成语音和动态合成画面，在第四轮复现百炼 `invalid_request_error`，message 为 `Error append image before append audio.`。模型会话仍可用，原实现将所有 error 都视作致命错误并释放了摄像头、麦克风和连接。

现在仅针对已确认的这一精确请求错误保留会话、本机预览和已有字幕，暂停视频发送；下一次检测到语音开始后，等待 500ms 再恢复视频。摄像头关闭或挂断时不会被恢复逻辑重新开启。未知或致命服务错误仍会完整停止采集并提示重拨，不忽略其他错误。

独立审查发现恢复回调可能提前解除相机切换操作锁，已加入独立 cameraOperation 状态并通过回归测试及复核。
