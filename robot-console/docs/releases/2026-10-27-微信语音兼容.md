# 2026-10-27 微信内置浏览器语音兼容

## 问题与修复

用户反馈：系统浏览器可用语音，微信内置浏览器显示识别服务被禁用。原来按住说话与电话都直接使用 Web Speech Recognition；接口对象存在不代表 WebView 允许调用识别服务。

- 微信优先走麦克风录音与服务器识别；普通浏览器保留原有识别，缺失内置识别能力时也可以走兼容通道。内置识别返回 service-not-allowed 时切换通道。
- 使用 Web Audio 采集单声道 PCM，在客户端转为 16 kHz WAV，避免 iOS 与 Android 编码格式差异。按住说话松手后提交；电话检测到停顿后提交一句话，完成问答与播报后再监听，避免录入自己的回复。
- 添加 /api/voice/transcribe，调用现有服务端千问配置的 qwen3-asr-flash。API Key 不进入客户端；音频只在请求内存中处理，不落盘、不写数据库、不输出音频或逐字稿日志。转写文字沿用现有的浏览器对话历史逻辑。
- 单次采集最多25秒，接口最多接受30秒/960,044字节规范PCM；接口校验同站来源、真实文件结构和流式体积。服务器同时识别最多2条、每IP每分钟最多30条，失败或限流给出重试提示。
- 取消、挂断、页面隐藏或离开时释放麦克风并取消上传，旧请求的转写不得发送到新会话。权限被拒绝时提示检查微信与系统麦克风授权。

## 验证记录

- 千问上游真实探测：现有配置识别合成音频，HTTP 200，转写为“磁铁能吸铁钉。”。
- 新增13项录音、转码、静音、取消、上游错误与接口输入测试通过；本地全仓96个Vitest文件、865项通过。TypeScript与本次7个代码/测试文件ESLint通过。
- 两份旧SciencePet源码正则契约在修改前与修改后均为72项中54项通过、18项失败，失败项相同；这些旧契约不记为通过。
- Browser插件不可用，使用Playwright Chromium、390×844、微信User-Agent、合成音频测试麦克风。按住说话与电话模式均未调用故意禁用的原生识别，/api/voice/transcribe返回200与“磁铁为什么能吸铁钉？”。电话模式获得科学回答并完成TTS接口请求（200）；页面无脚本错误。
- 真机微信未测试：模拟测试不能保证特定iPhone/Android微信版本提供麦克风权限。若微信本身不提供网页录音能力，保留文字输入及系统浏览器打开的清楚提示。
- 参考：阿里云Model Studio Qwen-ASR API参考，https://www.alibabacloud.com/help/en/model-studio/qwen-asr-api-reference ，核对input_audio Base64与asr_options参数。
