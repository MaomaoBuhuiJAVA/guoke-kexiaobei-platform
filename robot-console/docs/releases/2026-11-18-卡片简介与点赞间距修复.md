# 卡片简介与点赞间距修复

用户反馈手机端故事卡片的简介与点赞、浏览统计重叠。正式站复现确认：360、395、720px宽度下，科学诗和故事卡片简介末端比统计栏顶部低约22px；部分实验卡片也重叠约5px。

统计栏保持卡片白区右下角定位，在720px及以下为卡片正文底部明确预留52px，防止更紧凑的文学卡片样式覆盖统计栏空间。桌面布局与互动逻辑不变，不涉及数据库。

使用Playwright/Edge，在360×740、395×667、720×900、1011×667、1280×900检查三类卡片，每类检查前12张。修改后15组全部无重叠；手机端简介与统计栏最小间距13px，实验卡片16px，桌面保留原间距。无页面脚本错误。截图和几何测量记录保存在 `output/card-spacing-20261118`。

发布仍须使用GitHub Actions Linux包，在候选服务及公网复验；本记录初建时SSH连接超时，尚未切换正式版本。
