# 视频预览帧率优化

日期：2026-11-16

用户反馈全屏视频预览不流畅，原摄像头配置为目标10fps、最高15fps，本地预览与模型发送共享采集轨道。现改为采集目标30fps、最高30fps，保持960×540目标分辨率；AI端使用RTCRtpSender编码参数独立设置maxFramerate=10、maxBitrate=800000，不降低采集轨道帧率。

初次连接在SDP协商完成后设置编码参数；切换/重开摄像头时重新应用。保留原encodings与transactionId；浏览器不支持setParameters或拒绝可选参数时仍可通话，此时传输限帧属于尽力设置，不承诺所有平台强制生效。

验证：全量979项测试通过、19项原配置跳过；类型检查通过。新增测试覆盖预览采集与发送限帧、切镜头保持配置、浏览器拒绝可选参数兼容。独立代码审查无阻断发现。

实际浏览器用30fps合成画面与生成语音运行真实控制器，经公网SDP接口连接百炼：源轨道30fps、outbound-rtp统计10fps、编码maxBitrate800000/maxFramerate10，视觉问答正确，无服务错误。未使用用户真实设备内容；真机帧率仍受设备、光照和浏览器调度影响。
