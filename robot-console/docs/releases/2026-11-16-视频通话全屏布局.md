# 科小贝视频通话全屏布局

日期：2026-11-16

## 界面变化

按用户确认的参考布局改为网页可视区域全屏视频，取消浮层白色卡片与页面导航露出。顶部为科小贝通话状态、计时、对话记录、切换镜头及字幕开关。实时用户文字以小字显示，科小贝回复以大字显示在屏幕中下方、四个控制按钮上面。

底部从左到右：麦克风、扬声器、摄像头、挂断；用渐变遮罩保证亮背景下可读。字幕仅显示最新几行并自动跟随结尾，旋转屏幕时重新贴底。完整的本次对话可从顶部更多按钮打开，记录面板支持返回文字对话。挂断后可重拨，退出恢复背景交互与页面滚动。

手机使用 dvh 与安全区，铺满网页可视区域；浏览器地址栏与系统状态栏仍由浏览器控制。不改变媒体连接、服务端协议、模型配置、密钥或数据库。

## 验证

- TypeScript、修改组件 ESLint 及全量 976 项测试通过（19 项原配置跳过）。
- 实际组件使用生成的叶片/红圆画面和中文语音，经已配置百炼完成问答，模型正确描述可见图形；没有采集用户设备内容。
- 手机 390×844 下检查全屏画面、实时用户/AI 字幕、四按钮位置；实际验证字幕开关、静音恢复、历史记录、返回文字与退出。
- 短横屏 667×320 下字幕与顶部工具、底部按钮无重叠；字幕旋转后末尾可见。
- 页面后台仍按现有规则结束通话。浏览器平台的摄像头权限、移动端实机声音体验不因布局验证而视为重新验收。
- 本地临时验收路由已删除，不进入发布包。截图保存在本机 output，不提交用户资料或原始音视频。
