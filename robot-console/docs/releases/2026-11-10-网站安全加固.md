# 网站安全加固

用户要求修复网站公开面评估中可修复的技术问题，本轮不新增付费云产品。

## 最终行为

- 科学材料新增、上传、识别、封面生成统一要求有效会话，以及管理员或园方核验的教师身份；客户端只向这些用户展示添加入口。家长、未核验账号和匿名访客继续浏览公开资源。
- 四个写入口校验同源，并按可信账号限流；创建接口限制 JSON 和 multipart 总体大小。附件类型、大小及投稿字段均在 OSS 写入前校验，后续上传或数据库失败会清理本次创建的附件。
- 公共资源输出把“班级 + 幼儿姓名”署名及其在说明、正文、来源元数据中的重复出现替换为“小朋友”；媒体地址保留，原始资料与数据库不删除。
- 个性化 `/api/overview` 明确禁止共享缓存；禁止框架响应标识，增加短期、仅当前域的 HSTS 和必要的浏览器权限限制。
- CSP 的对象嵌入、页面基址、表单目标和框架嵌套限制直接生效。脚本、样式、连接和媒体的完整策略先以 Report-Only 部署，保留语音、AI、媒体兼容性验证空间，不能将此说成完整脚本 CSP 已强制执行。

## 验证与发布边界

新增回归测试覆盖未授权请求拒绝、跨站请求拒绝、按账号限流、权限查询失败关闭、附件校验先于写入、数据库失败后清理及公开文本脱敏。生产包由 GitHub Actions 的 Ubuntu / Node.js 22 构建和校验，ECS 不安装依赖、不构建、不做数据库迁移。

生产 SSH 连接超时，通过现有阿里云云助手核实当前版本为 `1776220e223b018fd329cc7c36d71f751a131985`，服务、Nginx、PostgreSQL active，磁盘剩余 18GB。部署保留当前版本，候选服务在独立端口验收，切换失败自动回滚。

不通过测试账号或有效投稿写生产库，不触发付费模型调用。未识别的隐私内容、图片/视频画面及监护人授权仍需园方逐条人工核查，技术规则不能替代内容审核。
