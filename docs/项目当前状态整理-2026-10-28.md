## 一、项目基本信息

### 1.1 项目概述
- **项目名称**: 国科二幼智慧成长平台（科小贝）
- **服务对象**: 龙湾区国科温州第二幼儿园
- **主要功能**: 园所官网、科学资源库、教学智能体、科学游戏、账号系统、作品管理

### 1.2 技术栈
```
前端: Next.js 16.2.9 (App Router) + React 19.2.3 + TypeScript 5.9.3
UI: Tailwind CSS 4.1.18 + Radix UI + Lucide Icons
后端: Next.js API Routes + Prisma 6.19.3
数据库: PostgreSQL (ECS 本机)
AI 服务: 千问 API (文本/视觉/图像/语音)
存储: 阿里云 OSS (guokemeitiku, oss-cn-hangzhou, 私有)
部署: 阿里云 ECS + Ubuntu + Node.js 22 + Nginx + systemd
```

### 1.3 生产环境
- **域名**: https://guokeey.cn (已验证在线 ✅)
- **最新发布**: 2026-10-27 微信语音兼容 (`20261027-wechat-voice-r1`)

## 八、安全与规范

### 8.1 安全边界
- ✅ 密码使用 bcrypt 单向哈希
- ✅ 管理员门禁：固定手机号 + ADMIN 角色 + 短信验证
- ✅ OSS bucket 私有，媒体通过签名 URL 访问
- ✅ 涉及危险实验（火焰等）返回安全替代说明
- ✅ 环境变量不提交到 Git
- ✅ 数据库 URL、手机号、对话内容不进入日志或文档

### 8.2 部署规范
- ✅ 使用受控发布包，禁止直接覆盖运行目录
- ✅ 发布前备份数据库
- ✅ 数据库变更使用增量 SQL 补丁 (`prisma/patches/`)
- ✅ 候选版本独立端口验收
- ✅ 原子切换 + HTTP 验收
- ✅ 保留上一版本用于回滚

### 8.3 Git 规范
- ✅ 只暂存相关文件，不使用 `git add -A`
- ✅ 提交信息清晰描述变更
- ✅ 发布后记录提交 SHA 和发布包 SHA-256
