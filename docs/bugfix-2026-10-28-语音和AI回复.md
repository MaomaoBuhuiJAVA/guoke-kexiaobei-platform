## 🐛 问题描述

### 问题 1: 语音输入状态提示残留

**现象**：
- 用户使用语音输入功能后，底部显示「语音已发送，正在等待回复」
- 这个提示不会自动消失，一直停留在界面上
- 影响用户体验，造成界面混乱

**截图位置**：
![语音输入 bug](附件视频截图)

**根本原因**：
- `SciencePet.tsx` 第 2097 行设置了 `voiceNotice` 状态
- 但在 `sendMessage` 函数中没有清除这个状态
- 导致提示信息残留在界面上

### 问题 2: AI 对话回复不智能

**现象**：
- 用户询问「小杯子」相关的科学问题
- 系统直接回复：「资料库暂未收录符合这些条件的内容。可以补充标题、年龄段或主题再找我。」
- 实际上 AI 应该运用科学知识回答，而不是简单地说「没有」

**截图位置**：
![AI 回复问题](附件截图)

**根本原因**：
- `run.ts` 第 166 行的提示词过于生硬
- 直接告诉 AI「本园资料库没有精确匹配到可直接引用的条目」
- 导致 AI 过于老实，直接回复「没有」，而不是运用知识回答

---

## ✅ 解决方案

### 修复 1: 清除语音状态提示

**文件**: `robot-console/src/components/SciencePet.tsx`

**修改位置**: 第 1784-1789 行

```typescript
async function sendMessage(prompt: string, options?: SendMessageOptions) {
  const content = prompt.trim();
  if (!content || busy || callActiveRef.current) return;

  // Clear voice notice when message is being sent
  setVoiceNotice("");

  const coverTarget = pendingPoetryCoverTargetRef.current;
  // ...
}
```

**说明**：
- 在发送消息时立即清除 `voiceNotice`
- 确保语音状态提示不会残留
- 不影响其他功能

### 修复 2: 优化 AI 提示词

**文件**: `robot-console/src/lib/native-workflow/run.ts`

**修改位置**: 第 162-167 行

**修改前**：
```typescript
{role:"user",content:`用户问题：${message}\n检索状态：本园资料库没有精确匹配到可直接引用的条目。请回答问题本身；如需设计活动，提供标注为原创的安全方案，不要伪称园本资料。`}
```

**修改后**：
```typescript
{role:"user",content:`用户问题：${message}\n\n园本资料库未检索到直接对应的条目。请运用科学知识直接回答教师的问题；如果问题涉及科学实验或活动设计，提供适合幼儿的探究方案（明确标注为"原创建议"）；不要把"资料库未命中"当作答复内容。`}
```

**改进点**：
1. ❌ 删除「检索状态」这样的技术性描述
2. ✅ 强调「运用科学知识直接回答」
3. ✅ 明确「不要把资料库未命中当作答复内容」
4. ✅ 提供原创方案时明确标注，保持透明度
