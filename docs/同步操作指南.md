# 代码同步操作指南

**生成时间**: 2026-10-28 09:37  
**适用场景**: 清理本地未提交改动，与 GitHub 和生产环境保持一致

---

## 🎯 目标

1. **保存**当前本地改动（注册优化 + 科学乐园入口）
2. **重置** main 分支到干净状态
3. **同步** GitHub 最新代码
4. **验证**本地环境正常工作

---

## 📋 执行步骤

### 步骤 1: 检查当前状态

```bash
# 查看工作区状态
git status

# 查看改动文件列表
git diff --stat

# 查看未跟踪文件
git ls-files --others --exclude-standard
```

**预期结果**: 应该看到 6 个已修改文件 + 7 个新增文件

---

### 步骤 2: 备份当前改动 ⭐ 重要

#### 方式 A: 创建备份分支（推荐）

```bash
# 1. 创建备份分支
git checkout -b backup/local-changes-20261028

# 2. 暂存所有改动
git add -A

# 3. 提交备份
git commit -m "backup: registration optimization and science park entry (uncommitted changes)"

# 4. 推送到 GitHub（可选，但推荐）
git push origin backup/local-changes-20261028

# 5. 返回 main 分支
git checkout main
```

**优点**: 
- ✅ 备份在 Git 历史中，有提交记录
- ✅ 可以推送到 GitHub，云端保存
- ✅ 随时可以通过分支名恢复

#### 方式 B: 使用 stash

```bash
# 保存到 stash
git stash push -m "WIP: registration optimization and science park entry"

# 查看 stash 列表
git stash list
```

**优点**: 
- ✅ 快速简单
- ⚠️ 只在本地，未推送到 GitHub

**推荐**: 使用**方式 A（备份分支）**，更安全可靠

---

### 步骤 3: 重置 main 分支

```bash
# 确保在 main 分支
git checkout main

# 拉取 GitHub 最新代码
git fetch origin

# 重置到远程 main（清理所有本地改动）
git reset --hard origin/main

# 清理未跟踪文件
git clean -fd
```

**警告**: `git reset --hard` 会**永久删除**未提交的改动！  
**确保步骤 2 已完成备份！**

---

### 步骤 4: 验证同步状态

```bash
# 检查 Git 状态（应该显示干净）
git status

# 查看提交历史
git log --oneline -5

# 确认分支一致
git log --oneline --graph --all --decorate -10
```

**预期结果**:
```
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
```

```bash
cd robot-console

npm ci

npm run dev
```

- ✅ 首页正常加载

## 🔄 恢复备份改动（如需要）

### 场景 1: 从备份分支恢复到新的 feature 分支

```bash
# 1. 从备份分支创建新的 feature 分支
git checkout -b feat/registration-and-mobile-nav backup/local-changes-20261028

# 2. 继续开发
# ...

# 3. 完成后推送
git push origin feat/registration-and-mobile-nav
```

---

### 场景 2: 从 stash 恢复

```bash
# 查看 stash 列表
git stash list

# 恢复最新的 stash
git stash pop

# 或恢复指定的 stash
git stash apply stash@{0}
```

## 🧪 测试检查清单

在提交任何代码前，必须通过以下测试：

```bash

npm test -- --run

npx tsc --noEmit

npm run build -- --webpack
```

## 📦 如何发布到生产

参考官方文档：`robot-console/docs/上线发布与ECS维护.md`

**关键步骤**:
1. ✅ 完整测试通过
2. ✅ 提交代码到 GitHub
3. ✅ SSH 连接到生产服务器
4. ✅ 数据库备份（如有 schema 变更）
5. ✅ 制作发布包（SHA-256 校验）
6. ✅ 候选版本验收
7. ✅ 原子切换 current 符号链接
8. ✅ 重启 guoke-web 服务
9. ✅ HTTP/HTTPS 验收
10. ✅ 更新发布记录文档

**警告**: 
- ⚠️ 绝不能直接覆盖运行目录
- ⚠️ 数据库变更必须先备份
- ⚠️ 失败时按脚本回滚

## 🚨 紧急回滚

如果新版本有问题：

```bash
# SSH 到服务器
ssh -i ~/.ssh/guoke.pem root@47.98.87.93

# 切换回上一个版本
sudo -u guoke ln -snf /opt/guoke/releases/20261027-wechat-voice-r1 /opt/guoke/current

# 重启服务
sudo systemctl restart guoke-web

# 验证
curl -I https://guokeey.cn
```
